# SPECTRUM learned gains — 实测结果（2026-11-01）

状态：**native executed**。`spectral_learned` 十轮在 Qwen2.5-Coder-7B-Instruct / MBPP500 / 4096 token 上完整跑完；对照 `tau08`、`adaptive`、固定 τ 运行至下述轮次。数据来自 `runs/spectrum_7b/*` 的原生 `evaluation.metrics.json`，未含模型权重、原始语料或私有随机化信息。

## 问题

固定 τ 的谱干预会随轮次累积收缩，导致 pass@1 崩塌。此前已用 `tau_decay=0.8`（tau08）和谱熵门控（adaptive）减缓但仍未阻止崩塌。本实验验证**每轮学习完整谱增益**（`spectral_learned`）是否优于标量 τ 控制——这是判断"方向级自由度是否有价值"、进而是否进入第二阶段（改 SFT loss）的关键。

## 四方法设置（除增益控制外完全一致）

| 方法 | 生成阶段增益控制 | SFT |
|---|---|---|
| 无 decay | 固定 τ=1.0 | 普通 LoRA SFT（loss_scope=all） |
| tau08 | τ=0.8ᵗ 固定衰减 | 同上 |
| adaptive | τ=(H_t/H_ref)^γ 谱熵门控 | 同上 |
| learned | 每轮学习完整谱增益 + KL 预算 + guard 检查 | 同上 |

四方法均为 4096 输出 / 6144 SFT token，同一模型与 MBPP291/50/30/500 划分。

## 结论

1. **learned 是唯一避免崩塌的方法**：p@1 峰值 0.5897（r5），r10 仍 0.5630；无 decay r8 已 0.5009、tau08 r9 0.5262、adaptive r8 0.5273。
2. **方向级自由度有明确价值**：learned 在 r5–r10 全程领先标量 τ 方法，r10 领先 tau08 r9 约 +3.7 点。
3. **学习过程稳定**：10/10 轮非恒等解、8/8 步接受、guard 未恶化、KL 在预算内，无一次回退。
4. **learned 自身也在缓慢下降**（0.5897→0.5630），提示方向级增益并非完全免疫多轮退化，但幅度远小于标量 τ。

对照说明：普通 SFT（`plain_7b_r10`，512 token，非本实验同长度）峰值 r5=0.5964、r10=0.5687；与 4096 token 的四方法存在长度差异，不可直接并列。
